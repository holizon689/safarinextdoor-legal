Privacy Policy

Safari Next Door Posting Tool
Last updated: November 14, 2026

1. What we collect

When the account owner connects TikTok, the Tool receives an access token and basic profile information (open ID, display name, avatar). Nothing else is collected.

2. How it is used

The token is used only to upload the channel's own videos to the TikTok inbox as drafts and to check the upload status. The profile information is shown only to confirm which account is connected.

3. Where it is stored

The token is stored in a local file on the creator's own computer. It is not sent to any server other than TikTok's, not sold and not shared with anyone.

4. Other people's data

The Tool does not access, collect or store any data about viewers or other TikTok users.

5. Deleting data

Disconnecting the Tool deletes the stored token. Access can also be removed in TikTok under Security and permissions > Apps and services.

6. Contact

Questions about these documents: open an issue at github.com/holizon689/safarinextdoor-legal/issues.
